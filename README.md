# C-Scripting in WebAssembly

This repository attempts to get the Symbol Set feature of the [C-Scripting repository](https://git.mr4th.com/mr4th-public/c-scripting) working with WebAssembly as the target. This repo uses [Pig Build](https://github.com/PiggybankStudios/PigBuild) as the build system and build for WebAssembly using Clang, but also supports building for Windows using MSVC compiler, to check against existing implementation of C Scripting Symbol Sets

**Github Pages Hosted Example:** [https://piggybankstudios.github.io/CScriptingInWasm/](https://piggybankstudios.github.io/CScriptingInWasm/) (See `index.html`)
